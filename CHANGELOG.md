# История изменений

## v1.1.0
- Новый эндпоинт `GET /health`: статус сервиса и его версия (ветка development, PR с автослиянием).
- Версия приложения выводится в `/health` и в документации API.

## v1.0.0
- API управления пользователями: создание, получение, список, изменение, удаление.
- Пароли хранятся как хеш argon2id, логин уникален без учёта регистра.
- 28 автоматических тестов (разработка через TDD, ПР4).
- CI на GitHub Actions: проверка форматирования, тесты на Python 3.11–3.13, автослияние PR из development.
- Автоматическая генерация документации и публикация на GitHub Pages.
